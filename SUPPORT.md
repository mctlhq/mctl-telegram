# Support

## Bugs and feature requests

Use [GitHub Issues](https://github.com/mctlhq/mctl-telegram/issues).

Before opening an issue, search existing issues to avoid duplicates. Use the provided templates so we have enough context to help.

**Important**: do not include Telegram session data, OAuth tokens, API credentials, phone numbers, chat IDs, or private message content in issues.

## Security vulnerabilities

Email **security@mctl.ai**. Do not open public issues for security reports. See [SECURITY.md](SECURITY.md).

## Questions and discussion

GitHub Discussions are not enabled on this repository. Open a [GitHub Issue](https://github.com/mctlhq/mctl-telegram/issues) for questions and ideas, or email **support@mctl.ai** for usage help.
