Questions

Is this an official Telegram app?

No. It is an independent, unofficial connector using the Telegram API, not affiliated with or endorsed by Telegram, Anthropic or OpenAI. It works only on the account you connect, and you remain responsible for following Telegram's terms.

Can it send messages on my behalf?

Only if you choose Read + send. In read-only mode send_message and send_media return a preview and nothing is delivered, and the other write tools refuse with an error. You can change this any time{{if .ShowManage}} on the manage page{{end}}.

What does my AI assistant see?

Your prompts, tool arguments and the results this server returns. The assistant's provider handles that traffic under its own policies. Listener-enabled Communication Agent accounts additionally store encrypted message and action content as described in /privacy.

How do I revoke access?

Remove the connector in Claude, disconnect{{if .ShowManage}} on the manage page{{else}} with the MCP tools{{end}}, or end the session in Telegram: Settings → Devices.

Which assistants does it work with?

Claude on web, desktop, mobile and Claude Code; ChatGPT by URL. Other MCP clients (Cursor, VS Code, Windsurf) may work but are not yet tested.

Is it open source?

Yes — github.com/mctlhq/mctl-telegram. Audit the code, self-host or contribute.
